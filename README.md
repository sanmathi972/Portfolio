# Sanmathi Ramesh — UX/UI portfolio

Upload the contents of this folder to the root of a GitHub Pages repository. Keep index.html, styles.css, script.js, resume.pdf and all asset folders together. No build step, API key, account or backend is required.

## Updated design

The selected Interface Atelier direction uses the first build’s cream, blue, navy and yellow palette. The immersive hero retains its original layout, headline, interactive career markers and scroll behavior with a new generated UX/UI design image with connected flows, wireframes and interface screens. The toolkit is now a blue accordion archive with an accessible open/close button and animated tool cards. Beyond the pixels presents profile-based learning, product thinking, design systems, AI exploration and Chennai content. Contact uses a new blue-and-gold glass-and-ribbon illustration and working email, phone and resume links. The notes wall and music player were removed.

Existing projects, career information, journey map, project selection box, process animation, draggable biography notes, floating navigation, theme toggle and resume are retained. No hobbies, portraits, employers or project results were invented. The six project dialogs contain supplied overviews rather than invented detailed case studies.

## Editing

Personal information and sections: index.html. Project and career data: PLACES, STOPS, WORK and TOOLS in script.js. New section styles are appended at the end of styles.css. Images: assets/atelier-hero.webp, atelier-toolkit.webp and atelier-contact.webp. Replace resume.pdf to update the downloadable resume.

## Assets and provenance

Three new raster illustrations were created using the built-in image generation tool for this update and compressed to WebP. Their prompts are recorded in asset-prompts.md. The retained reference-derived interaction code and remaining source assets originated from the supplied James Chugh visual target. This package does not assert a license for third-party source materials; use assets you have permission to publish. Fonts and Lenis are bundled for static hosting.

## Browser behavior

Desktop and tablet layouts become a single-column flow on small screens. Toolkit cards open and close with keyboard-accessible controls; reduced-motion preferences disable their entrance animation. Theme preference is stored locally. Email copy uses Clipboard API on HTTPS with a copy-selection fallback for local HTTP previews. Contact links open the visitor's mail/phone app; no form submissions or stored messages are involved.
